# peer-help-app

Платформа взаимопомощи студентов: поиск помощника по дисциплинам, рейтинг и награды.

## О проекте

Студенты часто не могут быстро найти того, кто объяснит сложную тему. Приложение соединяет тех, кому нужна помощь, с однокурсниками и старшекурсниками, которые сильны в нужной дисциплине.

## Основные функции

- Регистрация, выбор навыков: «В чём я силён» и «Где нужна помощь»
- Создание запроса помощи (дисциплина, тема, срочность, формат)
- Подбор помощника по навыкам, рейтингу и свободному времени
- Запись на сессию и чат (файлы, созвон)
- Оценка сессии и отзывы
- Бонусная система: рейтинг и уровни, достижения, таблица лидеров, челленджи, награды
