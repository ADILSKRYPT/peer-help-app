# Формула рейтинга

Рейтинг считается из таблицы `rating_log`: каждое начисление хранится отдельной строкой (пользователь, сессия, очки, причина, дата). Это позволяет пересчитать рейтинг при смене формулы и найти накрутку.

## Начисление очков

| Событие | Очки |
|---|---|
| Завершена сессия в роли помощника | +10 |
| Оценка от студента 5 звёзд | +5 |
| Оценка 4 звезды | +3 |
| Оценка 3 звезды | +1 |
| Оценка 1-2 звезды | -2 |
| Срочный запрос закрыт в течение суток | +3 |
| Получен новый бейдж | +5 |
| Подтверждённая жалоба на пользователя | -15 |

## Антинакрутка

- Очки за сессию начисляются только после оценки второй стороной.
- Не более 3 сессий в день с одним и тем же партнёром приносят очки.
- Сессии короче 10 минут очков не дают.

## Затухание

Очки старше 90 дней учитываются с коэффициентом 0,5, старше 180 дней с коэффициентом 0,25. Так рейтинг отражает недавнюю активность.

## Итоговый рейтинг

```
total_points = сумма(points × коэффициент затухания)
```

Результат сохраняется в `user_stats.total_points`.

## Уровни

| Уровень | Очки |
|---|---|
| 1. Новичок | 0-49 |
| 2. Помощник | 50-149 |
| 3. Наставник | 150-299 |
| 4. Эксперт | 300+ |

Уровень определяет доступные награды (`rewards.required_level`).

## Средняя оценка

`avg_stars` в `user_stats` считается как среднее значение `reviews.stars` по всем отзывам, где пользователь является `target_id`.
